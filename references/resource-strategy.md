# Just-in-Time Resource and Modality Strategy

## Rule

Choose a resource or modality only after identifying the learner's current bottleneck or when an explicitly requested artifact needs it. There is no source-type or modality quota.

## Selection Loop

1. Name the gap: missing prerequisite, misconception, weak procedure, poor transfer, or lack of evidence.
2. Define what the learner should do next.
3. Select the smallest representation or resource that enables that action.
4. Ask for a concrete output from it, then reassess before adding more.

Normally offer one or two resources at once. State why each is useful, the exact section or activity to use, and what the learner should report back. A link without a learner action is usually not instruction.

## Modality Router

- **Relationships or spatial structure:** diagram, annotated image, or physical model
- **Motion or change over time:** animation, video segment, simulation, or time-series plot
- **Numerical/computational behavior:** equation, hand calculation, code, notebook, plot, or profiler trace
- **Embodied/procedural behavior:** measurement, sensor log, photo/video, checklist, simulator, or physical trial with units and safety constraints
- **Verbal/conceptual reasoning:** dialogue, analogy, teach-back, comparison, or counterexample
- **Evidence evaluation:** primary text, dataset, competing sources, or claim-evidence table

Start with the cheapest adequate modality. Add a second modality only if the first leaves a specific gap or if translating between representations is itself the target skill.

## Source Quality

- Prefer authoritative or primary sources for definitions, specifications, and claims.
- Use video or community explanations when intuition or procedure is the bottleneck.
- Prefer current sources for changing tools and practices.
- Use `$deep-research` when the topic requires current multi-source research.

## Stop Conditions

Do not add another resource when the learner can already attempt the next evidence task. Do not produce a video, diagram, notebook, and reading list as a package unless the learner explicitly requests them and each has a distinct role.

## Anti-Patterns

- link dumps
- one resource category per concept by default
- media added for variety rather than need
- resources that replace the learner's attempt
- sending more material before reviewing the learner's current output
